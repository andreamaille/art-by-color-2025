# Button

A pill button in ink; the only filled control in the gallery.

- `abc-btn abc-btn--primary`: the one main action in a view (Show results, Copy as CSS).
- `abc-btn abc-btn--secondary`: outline, for the second action (Download palette, More filters).
- `abc-btn abc-btn--ghost`: underlined text, for low-stakes actions (Clear all).

Use a real `<button>`, or an `<a href>` when it navigates. Labels are verbs, sentence case. On the artwork page the primary button takes the palette's Feature color with Ground-colored text.
